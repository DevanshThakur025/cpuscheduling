# CPU Scheduling Simulator

A Python-based project that simulates CPU scheduling algorithms to demonstrate how operating systems allocate CPU time to processes.

## Features
- CPU scheduling algorithm simulation
- Process execution simulation
- Performance metrics analysis
- Modular Python architecture
- User interface support

## Tech Stack
- Python
- Operating Systems
- Process Scheduling

## Getting Started

Clone the repository:

```bash
git clone https://github.com/DevanshThakur025/cpuscheduling.git
cd cpuscheduling
```

Run the application:

```bash
python run_ui.py
```

## Learning Objectives
- Understand CPU scheduling algorithms.
- Analyze process execution and scheduling performance.
- Learn operating system concepts through simulation.
